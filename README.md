# Automatic Street Lighting System

## Project Description
This project automatically controls street lights based on surrounding light conditions using a light sensor and relay module.

## Components Used
- Arduino UNO
- Light Sensor Module
- Relay Module
- Street Light

## Working Principle
- In darkness, the sensor sends a HIGH signal.
- Arduino turns ON the relay and street light.
- In brightness, the sensor sends a LOW signal.
- Arduino turns OFF the relay.

## Technologies Used
- Arduino UNO
- Embedded C
- Sensor Interfacing
